단풍수첩 소개

메이플랜드를 하면서 매번 손으로 계산하고 여러 곳을 찾아 다니던 것을 한곳에 모은 모험 수첩이에요.

단풍수첩은 어떤 곳인가요

단풍수첩(danpungnote.com)은 메이플랜드를 하는 개인이 직접 만들고 운영하는 비공식 팬 사이트예요. 사냥터를 고를 때 "이 몬스터를 다 맞힐 수 있을까", 장비를 바꿀 때 "이게 정말 더 센가", 퀘스트를 할 때 "재료를 사서 깨도 남을까" 같은 질문에 숫자로 답하는 것을 목표로 해요.

회원가입이나 결제 없이 누구나 무료로 쓸 수 있어요. 운영비는 페이지에 나오는 광고로 마련해요.

할 수 있는 것

  • 명중 계산기: 내 레벨과 명중으로 몬스터를 100% 맞힐 수 있는지, 모자라면 DEX가 얼마나 더 필요한지 알려줘요.
  • 몬파·주차 계산기: 몬스터파크를 하루 2판씩 돌리면 목표일에 몇 레벨이 되는지, 원하는 레벨에 딱 맞춰 끝내려면 언제 몇 레벨로 시작해야 하는지 계산해요.
  • 효율 계산기: 스탯 공격력과 주스탯·부스탯·공격력 1당 효율, 아이템을 바꿨을 때 스공이 얼마나 바뀌는지 보여줘요.
  • 돈 되는 주문서 퀘스트: 주문서를 주는 퀘스트를 지역별로 모으고, 경매장 시세로 재료를 사서 깨면 얼마나 남는지 계산했어요.
  • 몬스터 도감(579종), 맵(741곳), 아이템 드랍 찾기(2,588개): 몬스터의 레벨·회피·필요 명중·드랍·출현 맵, 맵마다 나오는 몬스터, 아이템을 주는 몬스터를 서로 이어서 찾을 수 있어요.

데이터는 어디서 오고, 어떻게 확인하나요

  • 몬스터 능력치와 출현 맵: 메이플랜드가 바탕으로 하는 옛 메이플스토리(GMS 83) 원본 게임 데이터를 MapleStory.io에서 가져오고, 맵·몬스터 이름은 한국 서버 이름으로 바꿨어요. 메이플랜드에서 값이 다른 몬스터는 메이플랜드 기준으로 고쳤어요.
  • 드랍: 고전 메이플 서버 데이터(Cosmic, AGPL-3.0)를 바탕으로 다른 메이플랜드 자료와 하나하나 대조했어요. 어느 쪽에서도 확인되지 않은 드랍은 숨기고, 게임에서 직접 확인한 정정은 따로 기록해서 반영해요. 드랍률은 확실하지 않아서 넣지 않았어요.
  • 계산 공식: 명중·스공 공식은 메이플랜드 이용자들의 실험 결과와 옛 클라이언트 분석에 맞는 공식을 쓰고, 각 계산기 아래에 공식과 근거를 적어 두었어요. 넥슨이 공식 발표한 값은 아니에요.
  • 퀘스트 손익: 경매장 시세를 직접 조사한 날짜를 페이지 위에 적어 두었어요. 시세는 계속 바뀌니 참고용으로 봐 주세요.
